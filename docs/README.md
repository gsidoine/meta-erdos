# The Scottish Book — searchable book

The published [contemporary Scottish Book](https://gsidoine.github.io/the-scottish-book/) contains **46 current research entries**: 15 Acorns, 30 Seedbed questions and 1 Harvest result. The public repository and Pages URLs use the same project slug.

Canonical records are [data/problems.json](../data/problems.json) and [data/curation.json](../data/curation.json). Derived JSON copies and catalogue tables are regenerated by the existing script.

Use the [structured submission form](https://github.com/gsidoine/the-scottish-book/issues/new?template=propose-problem.yml) to propose a question, or see [Contributing](../CONTRIBUTING.md) for proofs, experiments and Lean contributions.

The [P001–P041 literature comparison](../audits/literature-comparison-P001-P041.md) records historical source comparisons, not a verified novelty certificate.

The earlier [P001–P030 portfolio consolidation](../audits/portfolio-consolidation-P001-P030.md) remains an archived research review.
