# The Problem Café — searchable book

The published [Problem Café](https://gsidoine.github.io/meta-erdos/) contains **46 current research entries**: 15 Acorns, 30 Seedbed questions and 1 Harvest result. The public project name can change without immediately renaming the GitHub repository or Pages URL.

Canonical records are [data/problems.json](../data/problems.json) and [data/curation.json](../data/curation.json). Derived JSON copies and catalogue tables are regenerated by the existing script.

Use the [structured submission form](https://github.com/gsidoine/meta-erdos/issues/new?template=propose-problem.yml) to propose a question, or see [Contributing](../CONTRIBUTING.md) for proofs, experiments and Lean contributions.

The [P001–P041 literature comparison](../audits/literature-comparison-P001-P041.md) records historical source comparisons, not a verified novelty certificate.
