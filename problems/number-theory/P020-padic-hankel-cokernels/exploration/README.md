# Higher-exponent obstructions

The unresolved case requires understanding random $p$-adic Hankel matrices beyond the first-order and low-rank classifications already proved.

In the all-exponent-two case with larger residual radical, the free third digits lie in a linear Hankel subspace but the nonlinear Schur-complement offset need not itself be Hankel. The unproved replacement of an affine translate by a uniform Hankel law would invalidate the proposed general formula.

See the [precise obstruction analysis](../../../../audits/P020-second-order-full-radical-obstruction.md), the [P020–P027–P033 adversarial audit](../../../../audits/2026-10-30-P020-P027-P033-research-audit.md), and the [historical dossier](../../P020-random-hankel-padic-cokernels.md).

An informative next result would classify the affine offset in the smallest $k=j=3<n$ case or furnish an explicit counterexample to the needed invariance.
