# Finite obstructions and tests

The full historical dossier is preserved at [P015's former location](../../geometry/P015-odd-area-lattice-triangulations.md). The program in [verification](../verification/P015_odd_area_flip_graph.py) enumerates valid triangulations and flips for four-color patterns through nine vertices.

**Established negative case.** With only three residue classes, every valid triangulation is isolated. Thus the four-class hypothesis cannot simply be discarded.

**Finite evidence.** Exhaustive four-class checks through $n=9$ found no disconnected state spaces with at least two valid triangulations. Random larger checks are evidence only, not proof.

The decisive open task is a general connectivity proof or a finite four-color obstruction. Experimental work should report exact parameter ranges and certificates.
