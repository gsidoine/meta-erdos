# Proposed problems awaiting mathematical review

Contributors may use the [structured problem form](../.github/ISSUE_TEMPLATE/propose-problem.yml). When a maintainer applies the \(prepare-draft-pr\) issue label, the workflow can create a draft PR with a directory \(submissions/issue-N/README.md\), optional \(statement.tex\), and machine-readable metadata.

**Submissions are not admitted research entries.** They receive a permanent \(Pxxx\) identifier and a place in the curated catalogue only after editorial review. Existing identifiers are not renumbered.

The workflow never runs submitted TeX, Markdown or scripts. It treats them as untrusted content; reviewer approval and CI are required before merging. If the repository has disabled GitHub Actions PR creation, the issue remains available for a maintainer to convert manually.
