# Formal verification

Problem-specific Lean work belongs in each problem's `formal/` directory. A shared, pinned Lean project may be added when the first genuine formalization is submitted; no empty `Pxxx.lean` placeholder is presented as a formal proof.

A repository statement is *Lean-verified* only when its exact declaration passes the pinned build. A formalized **statement** without a verified **solution** must be labeled accordingly. Informal mathematical proof, finite computation, Lean verification and historical novelty are separate assessments.
